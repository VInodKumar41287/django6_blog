# Django Learning Project - MyApp

A Django application featuring a blog app.

## Setup Instructions

1. **Create and activate a virtual environment:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # On macOS/Linux
   # or venv\Scripts\activate on Windows
   ```

2. **Install Django:**
   ```bash
   pip install django
   ```

3. **Run migrations:**
   ```bash
   python3 manage.py migrate
   ```

4. **Start the development server:**
   ```bash
   python3 manage.py runserver
   ```

5. **Visit the app:**
   Open [http://127.0.0.1:8000/blog/](http://127.0.0.1:8000/blog/) in your browser.
